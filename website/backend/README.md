# SAM (Software Asset Management) Backend

Бэкенд-сервис корпоративной системы управления программными активами и контроля лицензионного комплаенса.

## 🛠 Технологический стек

- **Язык и фреймворк**: Python 3.12+ / FastAPI / Uvicorn (ASGI)
- **База данных**: PostgreSQL 16 с расширением `pgvector`
- **ORM & Миграции**: SQLAlchemy 2.0 (AsyncIO) + Alembic
- **Драйвер БД**: `asyncpg` (высокопроизводительный асинхронный коннектор)
- **Безопасность**: JWT (Bearer tokens) + bcrypt
- **ИИ-модули**:
  - Умный мэтчинг имён процессов и нормализация в эталонный каталог (pgvector / fuzzy matching / LLM)
  - AI-анализатор условий лицензионных соглашений (EULA) на коммерческие риски и скрытые подписки
  - Чат-ассистент ИТ-директора (Text-to-SQL / RAG аналитика по живой БД)
- **Контейнеризация**: Docker & Docker Compose

## 🚀 Запуск сервиса

### 1. Запуск через Docker Compose (Рекомендуемый способ)

В корне папки `website/`:

```bash
docker compose up --build -d
```

Сервисы:
- `db`: PostgreSQL 16 + pgvector на порту `5432`
- `backend`: FastAPI API на `http://localhost:8000` (Swagger docs: `http://localhost:8000/docs`)
- `frontend`: Vue 3 SPA на `http://localhost:5173`

При первом запуске сервис автоматически:
1. Создаёт схему базы данных PostgreSQL и расширение `vector`.
2. Загружает справочники категорий ПО (Актуальный, Устаревший, Запрещённый к использованию).
3. Загружает классификатор разделов и классов ПО (по `data/Пример ПО.xlsx` и https://ru-ikt.ru/reestrpo).
4. Импортирует Единый реестр отечественного ПО из `data/Единый реестр российского ПО.xlsx`.
5. Инициализирует эталонный каталог разрешённого ПО и закупленные лицензии.
6. Выполняет первичный комплаенс-расчёт штрафных рисков, дефицита и выявления «зомби-софта».

---

### 2. Локальный запуск для разработки

```bash
cd website/backend

# Активация виртуального окружения
source venv/bin/activate

# Запуск приложения
PYTHONPATH=src uvicorn sam.main:app --host 0.0.0.0 --port 8000 --reload
```

## 📋 Основные эндпоинты REST API

Префикс: `/api/v1`

### 1. Аутентификация и первичная настройка
- `GET /api/v1/setup/status` — проверка инициализации системы (первый вход)
- `POST /api/v1/setup/init-admin` — создание аккаунта первого администратора
- `POST /api/v1/auth/login` — получение JWT токена
- `GET /api/v1/auth/me` — профиль текущего администратора

### 2. Главный дашборд
- `GET /api/v1/dashboard/summary` — общая статистика (ПК онлайн/офлайн, сотрудники, инсталляции, активные риски в рублях)
- `GET /api/v1/dashboard/compliance-overview` — распределение рисков по типам

### 3. Комплаенс-контроль и риски
- `GET /api/v1/compliance/balance` — таблица «Куплено vs Установлено», дефицит и штрафные риски
- `GET /api/v1/compliance/alerts` — журнал активных алертов (дефицит лицензий, зомби-софт, запрещённое ПО)
- `POST /api/v1/compliance/recalculate` — перерасчёт всех комплаенс-метрик

### 4. Управление активами
- `/api/v1/employees` — CRUD сотрудников компании
- `/api/v1/computers` — CRUD рабочих станций, привязка к сотрудникам
- `/api/v1/computers/{id}/software` — ручная привязка софта к ПК
- `/api/v1/catalog` — корпоративный белый список разрешённого ПО
- `/api/v1/licenses` — учёт закупленных лицензий, стоимости и условий EULA
- `/api/v1/categories` — категории ПО (Запрещённый, Устаревший, Актуальный)
- `/api/v1/installed-software` — реестр фактических установок ПО на хостах

### 5. Справочники
- `GET /api/v1/classifiers` — классификатор классов ПО РФ
- `GET /api/v1/registry` — поиск по Единому реестру отечественного ПО
- `POST /api/v1/registry/sync` — синхронизация с reestr.digital.gov.ru

### 6. Агент и импорт дампов
- `POST /api/v1/connector/agent/report` — приём отчёта от Go-агента с хоста
- `POST /api/v1/connector/agent/heartbeat` — фиксация онлайна хоста
- `POST /api/v1/connector/import/upload` — ручная загрузка файлов дампов (XLSX, CSV, JSON)
- `GET /api/v1/connector/import/history` — журнал выполненных импортов

### 7. ИИ-модули и Smart Matching
- `POST /api/v1/matcher/match-software` и `POST /api/v1/ai/match-software` — умный 4-этапный конвейер нормализации процесса:
  1. **Хэш файла**: проверка контрольной суммы бинарника (SHA-256) в базе известных сигнатур и ранее верифицированных записей (`confidence: 1.0`).
  2. **Единый реестр Российского ПО**: поиск среди ~22 000 отечественных программ по названию и альтернативным синонимам (`ru_software_registry`).
  3. **Wikimedia Semantic Search API**: семантический поиск по Wikipedia API с извлечением канонического названия продукта и вендора.
  4. **Нейросеть (OpenAI SDK)**: интеллектуальный анализ имени исполняемого файла с помощью модели (настраивается через `OPENAI_API_KEY`, `OPENAI_BASE_URL` и `OPENAI_MODEL`).
  5. **Локальные эвристики и алиасы**: фолбэк по нормализованным токенам и словарю системных процессов.
- `POST /api/v1/matcher/batch-normalize` и `POST /api/v1/ai/batch-normalize` — фоновая пакетная нормализация нераспознанных записей
- `POST /api/v1/ai/analyze-eula` — анализ текста лицензионного соглашения на коммерческие риски
- `POST /api/v1/ai/chat` — Text-to-SQL чат-ассистент ИТ-директора с естественным языком
