# SAM Frontend (Software Asset Management)

Веб-панель администратора для системы учёта и комплаенса программного обеспечения компании **SAM Enterprise**.

Разработана в соответствии со спецификацией из `FRONTEND.txt`, `SCHEMA_AND_API.md` и кейса хакатона.

---

## 🛠 Стек технологий

- **Фреймворк**: Vue 3 (Composition API, `<script setup>`) + TypeScript
- **Сборщик**: Vite 5
- **Стилизация**: Tailwind CSS (корпоративный светлый минималистичный дизайн в стиле shadcn/ui)
- **Иконки**: Lucide Icons
- **Управление состоянием**: Pinia 2
- **Маршрутизация**: Vue Router 4 (с защитой роутов и экраном первого запуска `/setup`)
- **API-клиент**: Axios с автоматическим fallback на реалистичные мок-данные при отсутствии запущенного бэкенда

---

## 🚀 Основные разделы и возможности

1. **Первоначальная настройка и Авторизация (`/setup`, `/login`)**:
   - При первом открытии (если сервис не инициализирован) предлагается создать профиль администратора (`username`, `password`, `full_name`).
   - Защита маршрутов через JWT Bearer токены.

2. **Главный дашборд (`/dashboard`)**:
   - Сводка в стиле Home Assistant: статус парка хостов (онлайн/офлайн), количество сотрудников, установленное ПО.
   - Финансовый штрафной риск дефицита лицензий в рублях.
   - Лента активных критических инцидентов.
   - Баланс ключевых лицензий с прогресс-барами.

3. **Экран «Комплаенс-контроль» (`/compliance`) — Ключевой экран системы**:
   - Наглядная таблица «Куплено vs Установлено» по каждому софту.
   - Подсветка критических зон:
     - **Штрафной риск**: дефицит лицензий (например, MS Office: куплено 100, установлено на 120 ПК $\to$ расчёт штрафного риска **500 000 руб.**).
     - **Зомби-софт и уволенные сотрудники**: софт не запускался >90 дней или закреплён за уволенными сотрудниками.
     - **Риски ИБ**: ПО из категории «Запрещённый к использованию» (торрент-клиенты) и нецелевое использование личных лицензий.
   - Кнопка принудительного перерасчёта правил комплаенса (`POST /api/v1/compliance/recalculate`).

4. **Сотрудники (`/employees`)**:
   - Просмотр, создание, редактирование и удаление сотрудников.
   - Карточка сотрудника с просмотром закреплённых за ним ПК и установленного софта.
   - Подсветка рисков, если сотрудник уволен, но ПК ещё числится за ним.

5. **Компьютеры и хосты (`/computers`)**:
   - Список рабочих станций со статусом сети (онлайн/офлайн), Hostname, BIOS Serial Number, IP, железом и ОС.
   - Привязка и смена сотрудника.
   - Детальный просмотр всех фактов установки софта на хосте с возможностью ручного добавления или удаления.

6. **Установленное ПО (`/installed-software`)**:
   - Сквозной реестр инсталляций со всех хостов.
   - Привязка категорий софта (Актуальный, Устаревший, Запрещённый).
   - Быстрый вызов ИИ-нормализации для неопознанных процессов.

7. **Каталог разрешённого ПО компании (`/catalog`)**:
   - Белый список компании: наименование, вендор, тип лицензии (Commercial, Open Source, Freeware, Trial), лимиты мест, ответственные и статус одобрения.

8. **Лицензии и соглашения (`/licenses`)**:
   - Учёт закупок лицензий, стоимости за единицу, моделей лицензирования (на устройство, на пользователя, site).
   - Хранение текста EULA и кнопка запуска ИИ-аудита соглашения.

9. **Категории софта (`/categories`)**:
   - Настройка категорий: Актуальный, Устаревший, Запрещенный к использованию.
   - Флаги проблемности и уровни риска (`none`, `low`, `medium`, `critical`).

10. **Классификатор ПО РФ (`/classifiers`)**:
    - Разделы и классы по `ru-ikt.ru/reestrpo` и файлу `Пример ПО.xlsx`.

11. **Единый реестр отечественного ПО (`/registry`)**:
    - Синхронизация с `reestr.digital.gov.ru`.
    - Отображение даты последнего обновления и кнопка принудительного обновления.

12. **Импорт дампа с рабочих станций (`/import`)**:
    - Форма drag-and-drop для загрузки файлов `.xlsx`, `.csv`, `.json` в формате колонок `COMPUTERS.SERIAL_NUMBER`, `SOFTWARE.DISPLAYNAME`, `SOFTWARE.PUBLISHER`, `SOFTWARE.VERSION` (как в `Пример дампа с компов.xlsx`).
    - Статистика по затронутым хостам и истории импортов.

13. **ИИ-компоненты**:
    - **Кейс А: Умный мэтчинг**: модальное окно для нормализации грязных имён процессов из ОС (например, `studio_visual_2022.exe` $\to$ `Microsoft Visual Studio 2022 Professional`) с процентом уверенности и обоснованием через pgvector & LLM.
    - **Кейс Б: AI-анализ EULA**: аудит условий лицензий на коммерческое использование, скрытые автоподписки и триалы.
    - **Кейс В: Чат-ассистент ИТ-директора**: диалог на естественном языке с преобразованием в SQL (Text-to-SQL) и выдачей аналитических сводок.

## 🏃 Запуск

### Режим разработки:
```bash
npm run dev
```
Сервер будет доступен по адресу: `http://localhost:5173`

### Продакшн-сборка:
```bash
npm run build
```
Собранные статические файлы находятся в директории `dist/`.
