# 🛡️ Где ПО, SAM? (Software Asset Management)

> **«Где ПО, SAM?»** — интеллектуальная enterprise-система управления программными активами, контроля лицензионного комплаенса, аудита уязвимостей (БДУ ФСТЭК) и автоматизации импортозамещения на базе ИИ.

---

## 🌟 Ключевые возможности

### 1. ⚖️ Лицензионный комплаенс и расчёт рисков
* **Автоматический баланс лицензий**: сопоставление купленных лицензионных договоров (`total_purchased`) с фактическими установками на рабочих станциях (`installed_count`).
* **Мгновенный расчёт дефицита и штрафов**: при $\text{installed} > \text{purchased}$ система фиксирует статус `critical_overuse` и рассчитывает финансовый штрафной риск в рублях:
  $$\text{Риск} = (\text{Установлено} - \text{Куплено}) \times \text{Цена за ед.}$$
* **Обнаружение «зомби-софта»**: выявление платного софта на станциях уволенных сотрудников или не запускавшегося более 60 дней (через Windows Prefetch).
* **AI-анализ договоров (EULA)**: нейросетевой разбор юридического текста лицензий с детекцией скрытых автопродлений, триал-периодов и запретов на коммерческое использование.

### 2. 🇷🇺 Автоматизированное импортозамещение
* **Интеграция с Единым реестром отечественного ПО Минцифры**: локальная синхронизация записей реестра и классификаторов программ (12 разделов, десятки классов).
* **Детекция зарубежного ПО**: автоматическая идентификация иностранного софта с выставлением статуса «Требует замены».
* **Подбор российских аналогов**: мгновенная рекомендация отечественных альтернатив из официального реестра по классам ПО (например, *Microsoft Office $\rightarrow$ МойОфис / Р-7 Офис*, *Oracle $\rightarrow$ Postgres Pro*, *Zoom $\rightarrow$ TrueConf*).

### 3. 🚨 Аудит уязвимостей БДУ ФСТЭК России
* **Синхронизация с базой ФСТЭК**: сопоставление установленного ПО и версий с базой данных угроз безопасности информации (БДУ ФСТЭК) и CVE.
* **Карточки уязвимостей на хостах**: оценка уровня опасности (Критический, Высокий), CVSS-скоринг, статус наличия эксплойтов в открытом доступе.
* **Рекомендации по устранению**: прямые меры нейтрализации уязвимостей от ФСТЭК России.

### 4. 🧠 Многоуровневый Smart Matching и ИИ-ассистент
* **7-ступенчатый гибридный конвейер нормализации ПО**:
  1. SHA-256 хэши исполняемых файлов.
  2. Эвристика путей установки и PE-заголовков (`.exe`, `vendor`).
  3. Обученная база сигнатур процессов (`ProcessSignature`).
  4. Поиск по Единому реестру отечественного ПО.
  5. Векторный семантический поиск по эмбеддингам (`pgvector`).
  6. Семантический поиск Wikimedia API.
  7. Нейросетевая нормализация через LLM.
* **AI-Ассистент ИТ-директора (Text-to-SQL)**: интерактивный чат на естественном языке с прямым формированием безопасных SQL-запросов к живой базе данных SAM.

### 5. 💻 Windows Go-Agent & Remote C2
* **Агент для рабочих станций**: сбор аппаратного BIOS SN, IP/MAC, установленных программ, запущенных процессов и даты последнего запуска (Prefetch).
* **Авторизация станций (Enrollment)**: двухэтапное подключение оборудования — новые ПК попадают в статус `pending` и не могут отправлять отчёты до одобрения администратором; возможность блокировки (`blocked`).
* **Удалённое управление (C2)**: очередь команд в Heartbeat-протоколе для удалённого запуска аудита (быстрый скан / глубокое сканирование диска).

### 6. 👥 Ролевые политики ПО для персонала
* Категоризация сотрудников («Разработка и ИТ», «Бухгалтерия и финансы», «Маркетинг и дизайн», «Общий персонал»).
* Политики разрешённого ПО: автоматическое формирование алертов ИБ при установке коммерческого ПО вне утверждённой роли сотрудника.

## 🏛 Архитектура проекта

```
SAM/
├── website/
│   ├── docker-compose.yml       # Оркестрация контейнеров (Postgres + pgvector, Backend, Frontend)
│   ├── backend/                 # FastAPI REST API, SQLAlchemy 2.0 (asyncpg), AI-модули
│   │   ├── src/sam/
│   │   │   ├── api/             # REST-контроллеры (компьютеры, лицензии, комплаенс, импорт, AI)
│   │   │   ├── models/          # ORM-модели БД PostgreSQL
│   │   │   ├── services/        # Smart Matcher, AI EULA, AI Chat, БДУ ФСТЭК, Registry Sync
│   │   │   └── main.py          # Точка входа FastAPI с фоновыми воркерами
│   │   └── tests/               # Набор модульных тестов
│   └── frontend/                # SPA-клиент (Vue 3, TypeScript, Vite, Tailwind CSS, Lucide Icons)
│       └── src/views/           # Дашборд, Комплаенс, Каталог, Лицензии, ПК, Импортозамещение
├── client/                      # Высокопроизводительный агент для Windows на Go (1.21+)
│   ├── cmd/agent/               # Демон службы, сбор инвентаризации, Prefetch, SHA-256
│   └── cmd/gui/                 # Локальный GUI-менеджер агента
└── data/                        # Справочники (Реестр отечественного ПО, уязвимости, дампы)
```

## 🚀 Быстрый запуск

### Вариант 1: Запуск через Docker Compose (Рекомендуемый)

Убедитесь, что у вас установлены Docker и Docker Compose.

```bash
cd website

# Сборка и запуск контейнеров в фоновом режиме
docker compose up --build -d
```

После старта будут доступны:
* 🌐 **Веб-интерфейс**: [http://localhost:5173](http://localhost:5173)
* 📚 **Документация Swagger API**: [http://localhost:8000/docs](http://localhost:8000/docs)
* 🗄 **PostgreSQL + pgvector**: `localhost:5432` (пользователь `sam_user`, база `sam_db`, пароль `sam_password`)

> **Автоинициализация:** При первом старте бэкенд автоматически создаёт таблицы, накатывает расширение `vector`, сидирует категории ПО, классификаторы, Реестр отечественного ПО, базу уязвимостей ФСТЭК и рассчитывает первичный комплаенс.

---

### Вариант 2: Локальный запуск для разработки

#### 1. Бэкенд (Python 3.12+)
```bash
cd website/backend

# Создание и активация виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск бэкенда
PYTHONPATH=src uvicorn sam.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. Фронтенд (Node.js 18+)
```bash
cd website/frontend

# Установка пакетов
npm install

# Запуск dev-сервера
npm run dev
```

#### 3. Windows-агент (Go 1.21+)
```bash
cd client
go build -o sam-agent.exe ./cmd/agent
./sam-agent.exe -server http://localhost:8000
```

## 🧪 Запуск тестов

Бэкенд покрыт набором автоматизированных тестов для проверки ключевых подсистем:

```bash
cd website/backend
for f in tests/test_*.py; do
  PYTHONPATH=.:src python "$f"
done
```

Тестируемые сценарии:
* `test_ai_chat.py` — Text-to-SQL пайплайн и откат на детерминированный движок.
* `test_ai_eula.py` — Разбор лицензий EULA, выявление автопродлений и запретов.
* `test_enrollment.py` — Авторизация рабочих станций, блокировка и допуск отчётов.
* `test_substitution_service.py` — Кэширование, rate limiter и подбор аналогов ПО.
* `test_employee_categories_and_agent_cmd.py` — Роли сотрудников и очередь C2-команд агента.
* `test_registry_sync.py` — Парсинг Единого реестра отечественного ПО.

## 🎯 Сценарий демонстрации на хакатоне (Demo Walkthrough)

Для показа всех ключевых преимуществ системы за 2–3 минуты:

### 1. Подготовка (до выхода)
1. В интерфейсе перейдите в **«Каталог ПО»** (`/catalog`) $\rightarrow$ проверьте или добавьте:
   * Название: `Microsoft Office Professional Plus 2021` (Тип: `Платный`).
2. В разделе **«Лицензии»** (`/licenses`) добавьте закупку:
   * Программа: `Microsoft Office Professional Plus 2021`, Количество: **1 шт.**, Цена: **45 000 ₽**.
3. В разделе **«Лицензионный комплаенс»** (`/compliance`) покажите чистый дашборд (рисков 0 ₽).

### 2. Загрузка дампа инвентаризации
Создайте файл `demo_dump.csv` со следующим содержимым:

```csv
COMPUTERS.SERIAL_NUMBER,SOFTWARE.DISPLAYNAME,SOFTWARE.PUBLISHER,SOFTWARE.VERSION
WS-FIN-01,Microsoft Office Professional Plus 2021,Microsoft Corporation,16.0.14332
WS-FIN-02,Microsoft Office Professional Plus 2021,Microsoft Corporation,16.0.14332
WS-DEV-01,7-Zip 19.00 (x64 edition),Igor Pavlov,19.00.00.0
WS-OFFICE-01,МойОфис Стандартный 2,ООО "НОВЫЕ ОБЛАЧНЫЕ ТЕХНОЛОГИИ",2.4.0
```

Перейдите в **«Загрузка дампа»** (`/import`) и загрузите файл.

### 3. Демонстрация результатов жюри
* **Дефицит лицензий и финансовые риски** (`/compliance`):
  Мгновенно появляется алерт: *«Дефицит лицензий: Microsoft Office (установлено 2 шт. при закупленной 1 шт.)»*. Штрафной финансовый риск: **45 000 ₽**.
* **Импортозамещение** (`/substitution`):
  Зарубежный MS Office получает статус *«Требует замены»* и список отечественных аналогов из реестра Минцифры (*МойОфис, Р-7 Офис*). `МойОфис Стандартный 2` помечается зелёным статусом *«Отечественное ПО»*.
* **Уязвимости БДУ ФСТЭК** (`/computers` $\rightarrow$ клик по ПК `WS-DEV-01` $\rightarrow$ вкладка *«Уязвимости БДУ ФСТЭК»*):
  Отображаются уязвимости программы `7-Zip 19.00`, оценка опасности CVSS 7.8+, наличие эксплойтов и меры по нейтрализации.
* **AI-Аналитика** (`/chat`):
  Задайте вопрос: *«Какой у нас финансовый риск по лицензиям и что нужно импортозаместить?»* — ИИ выдаст структурированный сводный отчёт на основе живых данных.
